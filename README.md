# SHTOR design site

Рабочий репозиторий сайта студии **SHTOR design**.

## Уже заложено
- пастельная дизайн-система на основе шалфейного цвета логотипа;
- премиальная, спокойная главная без визуального шума;
- крупный hero-блок;
- блоки услуг;
- журнальная асимметричная галерея;
- блок тканей и фактур;
- этапы работы;
- форма заявки;
- адаптив для телефона и планшета.

## Структура
- `index.html` — главная;
- `styles.css` — дизайн и адаптив;
- `script.js` — меню и базовая логика формы;
- `assets/logo.svg` — рабочая векторная версия логотипа по предоставленному макету.
